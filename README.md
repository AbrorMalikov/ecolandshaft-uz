# Eco Landshaft (ecolandshaft.uz)

O'zbekiston bo'ylab gazon ekish, sun'iy va tabiiy rulonli gazon sotish (optom va chakana), mini-futbol stadionlari, bolalar maydonchasi va EPDM rezina qoplamalarini qurish rasmiy veb-sayti.

## Asosiy xususiyatlar:
- **Texnologiya**: Pure Semantic HTML5, CSS3 (Apple Liquid Glass & Bento Card dizayni), Vanilla JavaScript
- **SEO-optimizatsiya**: 100% SEO-friendly, Schema.org mikro-belgilari, dinamik Sitemap.xml, Open Graph, Hreflang
- **5 tilli interfeys**: O'zbek (Lotin), O'zbek (Kirill), Rus, Ingliz, Xitoy (interaktiv kirillcha transliteratsiya bilan)
- **Konversiya vositalari**: Interaktiv narx kalkulyatori, Oldin/Keyin fototaqqoslash slayderi, EPDM rang konstruktori, faqat telefon raqamli tezkor ariza formasi (+998 maska)
- **Regional Programmatic SEO**: Toshkent, Samarqand, Farg'ona, Andijon, Buxoro, Qashqadaryo, Namangan viloyatlari uchun alohida lending sahifalari
- **Xizmatlar va Katalog**: 6 ta individual xizmat sahifasi, 3 ta e-commerce katalogi, biz haqimizda, blog va bog'lanish bo'limlari

## Saytni generatsiya qilish:
```bash
node build-site.js
```
Barcha 19 ta statik HTML sahifa va `sitemap.xml` avtomatik tarzda ildiz katalogida qayta hosil qilinadi.
